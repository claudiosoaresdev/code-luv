# Plano 2 — Aula: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A aluna abre a aula 1 ("Seu primeiro HTML"), lê a explicação, escreve HTML num editor de verdade, vê o resultado na janela retrô, confere item por item, pede pistas (e a solução, se quiser) e conclui a aula.

**Architecture:** Cada aula tem dois arquivos em `src/content/aulas/<nn-slug>/`: `explicacao.mdx` (texto, via `@next/mdx`) e `aula.ts` (metadados e prática, tipados). Um registro (`src/content/aulas/index.ts`) lista as aulas sem importar MDX — por isso dá para testar com Vitest; só a página importa o MDX, por `explicacoes.ts`. A página `/aulas/[slug]` fica num grupo de rotas próprio, `(aula)`, sem o cabeçalho principal (DS 5.3). A prática é um Client Component que orquestra o editor (CodeMirror 6 com wrapper próprio), o resultado (iframe `sandbox=""` dentro da `RetroWindow`), a conferência (feita **no pai**, com `DOMParser` sobre o texto da aluna — sem executar nada), as pistas e a conclusão. Nada é salvo: progresso e código persistidos chegam no Plano 4.

**Tech Stack:** Next.js 16.4 (App Router, `cacheComponents` e `partialPrefetching` ligados), React 19.3, TypeScript, Tailwind CSS 4, shadcn/ui (base-nova, Base UI, Lucide), `@next/mdx` 16.4, CodeMirror 6 (`@codemirror/*`), Vitest 5 + Testing Library + jsdom, Playwright + axe-core.

**Documentos de referência:**

- `docs/briefing.md` — CU-03 (praticar), CU-04 (errar e receber ajuda), HU-04, HU-05, HU-06; seção 9 (primeiro valor em até 10 minutos).
- `docs/design-system.md` (v0.2.3) — 5.2 "Aula dividida", 5.3 navegação dentro da aula, 8.2 fichas `CodeEditor`/`ResultPreview`/`CheckList`/`HintPanel`/`Toast`, 9 padrões "Estrutura da aula", "Conferência e pistas", "Conclusão de aula", "Desfazer", 10 voz, DS-08 (o site da aluna não herda estilos).
- `AGENTS.md` — esta versão do Next.js tem mudanças; consultar `node_modules/next/dist/docs/` antes de usar uma API. Em especial: `01-app/02-guides/mdx.md` e `01-app/02-guides/migrating-to-cache-components.md` (seção "generateStaticParams and dynamicParams").
- Skill `shadcn` (`~/.claude/skills/shadcn/SKILL.md`) — regras de composição.

**Decisões deste plano (tomadas com a responsável pelo produto em 2026-10-09):**

- Conteúdo em **MDX**; dados da prática em TypeScript ao lado do MDX.
- Editor **CodeMirror 6**, montado com os pacotes `@codemirror/*` (sem `@uiw/react-codemirror`, que traria `@babel/runtime` e um tema que não usamos).
- **Só a aula 1** com conteúdo completo. Outras aulas viram trabalho de conteúdo (um `aula.ts` + um `explicacao.mdx` + uma linha no registro), sem código novo.

**Decisões técnicas (e por quê):**

- **Conferência sem executar o código da aluna.** A aula 1 é só HTML: as checagens (`existe`, `texto`, `quantidade`) rodam com `DOMParser` no próprio componente, que não executa scripts. O iframe do resultado usa `sandbox=""` (sem scripts, sem acesso à página). Quando chegarem aulas com JavaScript, a conferência passa a rodar dentro do iframe, com `postMessage` — fora deste plano.
- **Sem fechamento automático de tags no editor** (`html({ autoCloseTags: false })`): fechar a tag é justamente o que a aula 1 ensina, e a conferência é que ajuda.
- **`Tab` não fica preso no editor** (sem `indentWithTab`): quem navega por teclado precisa sair do editor com `Tab`.
- **Com `cacheComponents`, `dynamicParams` quebra o build.** Slugs desconhecidos são tratados com `notFound()` na página, e `generateStaticParams` precisa devolver pelo menos uma aula.

**Convenções do repositório:** Prettier sem ponto e vírgula, aspas simples, `trailingComma: 'all'`; ESLint ordena imports (`simple-import-sort`); testes em `src/**/*.spec.{ts,tsx}` importando de `vitest` (`globals: false`, setup com jest-dom e cleanup em `vitest.setup.ts`); commits Conventional Commits em minúsculas, com o trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; links com cara de botão = `<Link className={buttonVariants(...)}>`, nunca `<Button render={<Link />}>`; área de toque mínima 48px. Sem a pasta `.next`, rode `npx next typegen` antes de `npx tsc --noEmit` (os tipos globais `LayoutProps`/`PageProps` vêm dele).

- [ ] **Step 4: Implementar**

`src/lib/checks/run-checks.ts`:

```ts
import type { Check, CheckResult } from './types'

function passes(doc: Document, check: Check) {
  switch (check.tipo) {
    case 'existe':
      return doc.querySelector(check.seletor) !== null
    case 'texto':
      return (doc.querySelector(check.seletor)?.textContent ?? '').trim() !== ''
    case 'quantidade':
      return doc.querySelectorAll(check.seletor).length >= check.minimo
  }
}

/**
 * Confere o HTML da aluna sem executá-lo: o DOMParser monta o documento,
 * mas não roda scripts. Serve para aulas só de HTML; aulas com JavaScript
 * vão precisar conferir dentro do iframe do resultado.
 */
export function runChecks(html: string, checks: Check[]): CheckResult[] {
  const doc = new DOMParser().parseFromString(html, 'text/html')
  return checks.map((check) => ({
    descricao: check.descricao,
    ok: passes(doc, check),
  }))
}
```

import { aula as seuPrimeiroHtml } from './01-seu-primeiro-html/aula'
import type { Aula } from './types'

/**
 * Todas as aulas, em ordem. Para acrescentar uma aula: criar a pasta
 * nn-slug/ com aula.ts e explicacao.mdx, importar aqui e registrar o MDX
 * em explicacoes.ts. Este arquivo não importa MDX, para poder ser testado.
 */
export const AULAS: Aula[] = [seuPrimeiroHtml].sort((a, b) => a.ordem - b.ordem)

export function getAula(slug: string) {
  return AULAS.find((aula) => aula.slug === slug)
}

export function proximaAula(slug: string) {
  const i = AULAS.findIndex((aula) => aula.slug === slug)
  return i === -1 ? undefined : AULAS[i + 1]
}
```

Toda página da internet é um arquivo de texto escrito em **HTML**. O navegador lê esse texto e desenha a página na tela.

O HTML usa **tags** para dizer o que cada coisa é. Uma tag é como uma etiqueta: `<h1>` diz "isto é um título", e `<p>` diz "isto é um parágrafo".

<h1>Olá, eu sou a Luv!</h1>

'use client'

import { useState } from 'react'
import { LightbulbIcon } from 'lucide-react'

import { Alert, AlertDescription, AlertTitle } from '@/components/ui/alert'
import { Button } from '@/components/ui/button'

type HintPanelProps = {
  pistas: string[]
  solucao: string
}

/**
 * Pistas progressivas (DS 8.2 — HintPanel): uma de cada vez; "Ver solução"
 * só depois da última. Nada aqui indica perda ou penalidade.
 */
export function HintPanel({ pistas, solucao }: HintPanelProps) {
  const [abertas, setAbertas] = useState(0)
  const [solucaoAberta, setSolucaoAberta] = useState(false)
  const temMaisPistas = abertas < pistas.length

  return (
    <div className="flex flex-col gap-3">
      {abertas > 0 && (
        <Alert variant="warning">
          <LightbulbIcon />
          <AlertTitle>
            Pista {abertas} de {pistas.length}
          </AlertTitle>
          <AlertDescription>{pistas[abertas - 1]}</AlertDescription>
        </Alert>
      )}

      {solucaoAberta && (
        <div className="flex flex-col gap-2">
          <p className="text-sm font-semibold">Uma solução possível</p>
          <pre className="overflow-x-auto rounded-lg border-2 border-border bg-popover p-4 font-mono text-sm leading-relaxed">
            {solucao}
          </pre>
        </div>
      )}

      {temMaisPistas ? (
        <Button
          variant="outline"
          className="w-fit"
          onClick={() => setAbertas((n) => n + 1)}
        >
          {abertas === 0 ? 'Ver pista' : 'Ver próxima pista'}
        </Button>
      ) : (
        !solucaoAberta && (
          <Button
            variant="outline"
            className="w-fit"
            onClick={() => setSolucaoAberta(true)}
          >
            Ver solução
          </Button>
        )
      )}
    </div>
  )
}

'use client'

import { useEffect, useRef } from 'react'
import { defaultKeymap, history, historyKeymap } from '@codemirror/commands'
import { html } from '@codemirror/lang-html'
import { HighlightStyle, syntaxHighlighting } from '@codemirror/language'
import { EditorState } from '@codemirror/state'
import {
  EditorView,
  highlightActiveLine,
  highlightActiveLineGutter,
  keymap,
  lineNumbers,
} from '@codemirror/view'
import { tags } from '@lezer/highlight'

// Cores do código (DS 8.2 — CodeEditor): tags em link (pink.400),
// atributos em violet.300, valores em rosa-bebê, comentários em ink.400.
// Todas ≥ 4.5:1 sobre bg-popover (garantido por src/app/tokens.spec.ts).
const highlight = HighlightStyle.define([
  { tag: [tags.tagName, tags.angleBracket], color: 'var(--link)' },
  { tag: tags.attributeName, color: 'var(--violet-300)' },
  { tag: tags.attributeValue, color: 'var(--pink-100)' },
  { tag: tags.comment, color: 'var(--ink-400)' },
])

const theme = EditorView.theme(
  {
    '&': {
      backgroundColor: 'var(--popover)',
      color: 'var(--foreground)',
      fontSize: '15px',
    },
    '&.cm-focused': { outline: 'none' },
    '.cm-content': {
      fontFamily: 'var(--font-jetbrains), ui-monospace, monospace',
      padding: '12px 0',
      caretColor: 'var(--primary)',
    },
    '.cm-cursor': { borderLeftColor: 'var(--primary)' },
    '.cm-gutters': {
      backgroundColor: 'var(--popover)',
      color: 'var(--ink-400)',
      border: 'none',
    },
    '.cm-activeLine, .cm-activeLineGutter': {
      backgroundColor: 'var(--accent)',
    },
    '&.cm-focused .cm-selectionBackground, .cm-selectionBackground, ::selection':
      { backgroundColor: 'var(--highlight)' },
  },
  { dark: true },
)

type CodeEditorProps = {
  value: string
  onChange: (value: string) => void
  /** Nome acessível do campo de código. */
  label: string
}

/**
 * Editor de HTML. Sem fechamento automático de tags (fechar é o que a aula
 * ensina) e sem prender o Tab (quem usa teclado precisa sair do editor).
 */
export function CodeEditor({ value, onChange, label }: CodeEditorProps) {
  const host = useRef<HTMLDivElement>(null)
  const view = useRef<EditorView | null>(null)
  const onChangeRef = useRef(onChange)

  useEffect(() => {
    onChangeRef.current = onChange
  })

  // Cria o editor uma vez. Trocas de `value` vindas de fora (Recomeçar,
  // Desfazer) são aplicadas pelo efeito seguinte.
  useEffect(() => {
    const editor = new EditorView({
      parent: host.current!,
      state: EditorState.create({
        doc: value,
        extensions: [
          lineNumbers(),
          highlightActiveLine(),
          highlightActiveLineGutter(),
          history(),
          keymap.of([...defaultKeymap, ...historyKeymap]),
          html({ autoCloseTags: false }),
          syntaxHighlighting(highlight),
          theme,
          EditorView.lineWrapping,
          EditorView.contentAttributes.of({ 'aria-label': label }),
          EditorView.updateListener.of((update) => {
            if (update.docChanged) {
              onChangeRef.current(update.state.doc.toString())
            }
          }),
        ],
      }),
    })
    view.current = editor
    return () => {
      editor.destroy()
      view.current = null
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps -- criado uma vez; `value` é sincronizado abaixo
  }, [])

  useEffect(() => {
    const editor = view.current
    if (editor && editor.state.doc.toString() !== value) {
      editor.dispatch({
        changes: { from: 0, to: editor.state.doc.length, insert: value },
      })
    }
  }, [value])

  return (
    <div
      ref={host}
      className="min-h-40 overflow-hidden rounded-lg border-2 border-border focus-within:outline-3 focus-within:outline-offset-2 focus-within:outline-ring"
    />
  )
}
```

```tsx
'use client'

import { useState } from 'react'

import { LuvSays } from '@/components/luv/luv-says'
import { Button } from '@/components/ui/button'
import { toast } from '@/components/ui/toast'
import type { Aula } from '@/content/aulas/types'
import { runChecks } from '@/lib/checks/run-checks'
import type { CheckResult } from '@/lib/checks/types'

import { CheckList } from './check-list'
import { CodeEditor } from './code-editor'
import { HintPanel } from './hint-panel'
import { LessonDone } from './lesson-done'
import { ResultPreview } from './result-preview'

type PracticeProps = {
  aula: Aula
  proxima?: { slug: string; titulo: string }
}

function falaDaLuv(faltam: number) {
  if (faltam === 0) return 'Funcionou! Agora é só concluir a aula.'
  return faltam === 1
    ? 'Quase! Falta 1 item. Quer uma pista?'
    : `Quase! Faltam ${faltam} itens. Quer uma pista?`
}

/**
 * Prática da aula (DS 9 — Estrutura da aula, Conferência e pistas,
 * Conclusão de aula, Desfazer). Nada é salvo ainda (Plano 4).
 */
export function Practice({ aula, proxima }: PracticeProps) {
  const { pratica } = aula
  const [codigo, setCodigo] = useState(pratica.inicial)
  const [resultados, setResultados] = useState<CheckResult[] | null>(null)
  const [mostrarPistas, setMostrarPistas] = useState(false)
  const [concluida, setConcluida] = useState(false)

  const faltam = resultados?.filter((r) => !r.ok).length ?? 0
  const tudoCerto = resultados !== null && faltam === 0

  function mudarCodigo(novo: string) {
    setCodigo(novo)
    setResultados(null) // conferência antiga não vale para o código novo
  }

  function conferir() {
    const novos = runChecks(codigo, pratica.conferencia)
    setResultados(novos)
    if (novos.some((r) => !r.ok)) setMostrarPistas(true)
  }

  function recomecar() {
    const anterior = codigo
    mudarCodigo(pratica.inicial)
    toast.add({
      title: 'Exercício recomeçado',
      description: 'Seu código voltou para o começo.',
      timeout: 6000,
      actionProps: {
        children: 'Desfazer',
        onClick: () => mudarCodigo(anterior),
      },
    })
  }

  function concluir() {
    setConcluida(true)
    toast.add({ title: 'Aula concluída', description: aula.titulo })
  }

  if (concluida) {
    return <LessonDone titulo={aula.titulo} proxima={proxima} />
  }

  return (
    <section aria-labelledby="pratica" className="flex flex-col gap-5">
      <h2 id="pratica" className="font-display text-2xl font-semibold">
        Prática
      </h2>

      <ol className="flex list-decimal flex-col gap-1 pl-5 text-base">
        {pratica.enunciado.map((passo) => (
          <li key={passo}>{passo}</li>
        ))}
      </ol>

      <CodeEditor
        value={codigo}
        onChange={mudarCodigo}
        label="Seu código HTML"
      />
      <ResultPreview html={codigo} />

      <div className="flex flex-wrap gap-3">
        <Button variant={tudoCerto ? 'outline' : 'default'} onClick={conferir}>
          Conferir
        </Button>
        <Button variant="outline" onClick={recomecar}>
          Recomeçar
        </Button>
      </div>

      <CheckList
        itens={pratica.conferencia.map((c) => c.descricao)}
        resultados={resultados}
      />

      {/* Região viva persistente: a fala troca aqui dentro e é anunciada. */}
      <div role="status">
        {resultados !== null && (
          <LuvSays
            announce={false}
            state={tudoCerto ? 'comemorar' : 'incentivo'}
          >
            {falaDaLuv(faltam)}
          </LuvSays>
        )}
      </div>

      {mostrarPistas && (
        <HintPanel pistas={pratica.pistas} solucao={pratica.solucao} />
      )}

      <div className="flex flex-col gap-2">
        <Button
          size="lg"
          className="w-fit"
          disabled={!tudoCerto}
          aria-describedby={tudoCerto ? undefined : 'concluir-ajuda'}
          onClick={concluir}
        >
          Concluir aula
        </Button>
        {!tudoCerto && (
          <p id="concluir-ajuda" className="text-sm text-muted-foreground">
            Confira o exercício: quando todos os itens estiverem certos, você
            conclui a aula.
          </p>
        )}
      </div>
    </section>
  )
}
```
