## Para que serve uma lista

Listas aparecem em todo lugar. Lista de compras, lista de tarefas, passo a passo de uma receita. No HTML também.

## A lista com marcadores

A tag `<ul>` cria uma lista com bolinhas na frente de cada item. Cada item fica dentro de um `<li>`.

O `<ul>` é a caixa da lista. Os `<li>` são as coisas guardadas dentro dela.

## A lista numerada

Quando a ordem importa, use `<ol>` no lugar de `<ul>`. O navegador numera os itens sozinho: um, dois, três.

## Exemplo

```html
<h2>O que a Luv mais gosta</h2>
<ul>
  <li>Dormir no teclado</li>
  <li>Caçar o cursor</li>
  <li>Aprender tags novas</li>
</ul>
```

Os espaços no começo das linhas não mudam nada na página. Eles só deixam o código mais organizado para ler.
