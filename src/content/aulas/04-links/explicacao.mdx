## O que é um link

Link é o texto que você clica para ir a outra página. É ele que liga as páginas da internet umas às outras.

## A tag de link

O link usa a tag `<a>`. O texto entre `<a>` e `</a>` é o que aparece na tela para clicar.

Mas o link precisa saber para onde ir. Isso fica num **atributo**, uma informação extra dentro da tag de abrir.

## O atributo href

O atributo do endereço se chama `href`. Ele vem depois do nome da tag, com um sinal de igual e o endereço entre aspas.

O endereço completo começa com `https://`. Copie o endereço da barra do navegador para não esquecer nenhuma letra.

## Exemplo

```html
<p>Eu aprendo no <a href="https://www.wikipedia.org">Wikipédia</a>.</p>
```

Escreva um texto que diga para onde o link leva. "Clique aqui" não ajuda quem está ouvindo a página.
