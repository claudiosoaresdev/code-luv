## Tags que dão nome às partes

Até aqui, cada tag disse o que é um pedaço de texto: título, parágrafo, lista. Agora vamos dar nome a partes inteiras da página.

Isso se chama **HTML semântico**. Semântico quer dizer "que tem significado".

## A seção

A tag `<section>` junta um assunto: um subtítulo e o que vem com ele. É como uma gaveta com etiqueta.

Na tela, nada muda. Mas o navegador, os buscadores e os leitores de tela entendem melhor como a página está organizada.

## O rodapé

O `<footer>` é o rodapé, a parte de baixo da página. Ali costumam ficar o nome de quem fez o site e formas de contato.

Existem outras tags assim. O `<header>` é o cabeçalho, e o `<main>` guarda o conteúdo principal.

## Exemplo

```html
<section>
  <h2>Meus planos</h2>
  <p>Quero aprender CSS para deixar meu site colorido.</p>
</section>
<footer>
  <p>Feito pela Luv com o CodeLuv</p>
</footer>
```
