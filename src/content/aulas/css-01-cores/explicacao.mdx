## O que é CSS

O HTML diz o que cada coisa é. O **CSS** diz como cada coisa aparece: cor, tamanho, espaço e lugar na tela.

O seu CSS fica separado do HTML. O navegador junta os dois na hora de desenhar a página.

## Uma regra de CSS

O CSS é feito de **regras**. Cada regra começa com um **seletor**, que diz em quais tags ela vale. Depois vêm as chaves.

Dentro das chaves ficam as **propriedades**. Cada uma tem um nome, dois-pontos, um valor e ponto e vírgula no fim.

## Cores

A propriedade `color` muda a cor do texto. A propriedade `background-color` muda a cor do fundo.

O valor pode ser o nome de uma cor em inglês, como `pink` ou `purple`. Existem mais de cem nomes prontos.

Escolha cores com muita diferença entre o texto e o fundo. Assim todo mundo consegue ler.

## Exemplo

```css
body {
  background-color: lavender;
}

h1 {
  color: purple;
}
```

A regra do `body` vale para a página inteira. A regra do `h1` vale só para os títulos.
